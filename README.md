## 🌟 Giới Thiệu
**Crochet Kids** là ứng dụng web tương tác được thiết kế đặc biệt dành riêng cho trẻ em học móc len (Crochet). Với giao diện màu sắc pastel ngọt ngào, hiệu ứng âm thanh sinh động, cùng các bài học và dự án được chia nhỏ dễ hiểu, bé có thể vừa chơi vừa tự tay làm ra những món đồ len bé nhỏ đáng yêu!

---

## ✨ Tính Năng Nổi Bật

- 🪢 **Lớp Học 5 Mũi Móc Cơ Bản:** Hướng dẫn từng bước với ví dụ ẩn dụ trực quan (Nút thắt kỳ diệu, Mũi bính `ch`, Mũi đơn `sc`, Mũi kép `dc`, Vòng tròn ma thuật `MR`).
- 🪄 **Góc Móc Tương Tác:** Bé bấm chuột/màn hình để tự tay "móc" từng mũi len trên web, tích lũy điểm sao và xem chuỗi len dài ra sống động.
- 🐙 **Dự Án Mẫu Dễ Thương:** Chú Sứa Bảy Sắc Cầu Vồng, Ngôi Sao May Mắn, Trái Tim Thỏ Bông, Bông Hoa Xinh Xắn với danh sách tích checklist từng bước.
- 🎨 **Studio Phối Màu Cuộn Len:** Thử nghiệm chọn màu thân, màu viền và phụ kiện cho thú bông len trước khi làm thật.
- 🏆 **Hệ Thống Huy Chương & Đổi Sao:** Tự động lưu tiến trình học của bé vào bộ nhớ trình duyệt (`localStorage`).
- 🔊 **Web Audio Synthesizer:** Hiệu ứng âm thanh sinh động không dùng file mp3 ngoài, nhẹ và mượt mà trên mọi thiết bị.

## 🚀 Hướng Dẫn Chạy Local

1. **Clone repository:**
   ```bash
   git clone https://github.com/infinitehorizons2012-code/crochet.git
   cd crochet
   ```

2. **Cài đặt thư viện:**
   ```bash
   npm install
   ```

3. **Chạy ứng dụng thử nghiệm:**
   ```bash
   npm run dev
   ```

4. **Build sản phẩm & Deploy:**
   ```bash
   npm run build
   npm run deploy
   ```
